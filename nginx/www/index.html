API endpoints

GET /pdb/<PDB-ID>

JSON document with parsed properties: residues, chains, helices, sheets, formulas, isoelectric point, amino-acid percentages.

/pdb/5ABY
GET /pdb/<PDB-ID>/<PDB-ID>.pdb

Original asymmetric-unit PDB file (text).

/pdb/5ABY/5ABY.pdb
GET /assembly/<PDB-ID>/<PDB-ID>.pdb1

Biological-assembly PDB file (text).

/assembly/101D/101D.pdb1
GET /assembly/<PDB-ID>/<size>.png

Rendered PyMol image of the biological assembly. Available sizes: 100x100, 200x200, 400x400.

/assembly/101D/400x400.png
GET /view/<view-name>

Query a CouchDB view in _design/query. The jsmol view returns proteins with one peptidic sequence, ≥1 helix and 1 sheet, and a small ligand.

/view/jsmol?include_docs=true
GET /stats/<view-name>

Aggregated statistics in _design/stats. Use ?group=true to break results down by key. Available views: byYear, byExperiment.

/stats/byYear?group=true
